# Duskwing

Аркада в духе flappy-механики: одна кнопка, пять уровней с целями и бесконечный режим после
прохождения. Проект построен вокруг одной архитектурной границы: `src/game/**` — чистый
TypeScript без единого импорта `react` и `pixi.js`, он знает только о числах и своём состоянии,
а рендер получает состояние снаружи через интерфейс `Renderer` (`src/game/types.ts`). PixiJS —
всего лишь одна из реализаций этого интерфейса в `src/render/pixi/`, React — оболочка в
`src/ui/`; благодаря этому логика покрывается тестами без jsdom и без единого пикселя на экране,
а граница держится не на договорённости, а на проверке — `tests/game-boundary.test.ts` грепает
исходники и падает, если импорт всё же появился. Запуск: `npm install`, затем `npm run dev`;
проверки — `npm run typecheck`, `npm run lint`, `npm run test`; сборка — `npm run build`.
